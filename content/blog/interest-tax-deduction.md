## 不知道這項扣除額 = 每年白丟好幾萬

每年 5 月報所得稅時，「自用住宅購屋借款利息」這項列舉扣除額是房貸族**最容易漏報**的項目之一。

每戶每年最高可扣 **30 萬**——以邊際稅率 20% 為例，等於少繳 **6 萬元**所得稅。連續 30 年總共可能省下 100 萬以上。

但要符合資格、要算清楚金額、要保留正確單據才能成功扣抵。本文一次說清。

> 📅 法規數字以財政部最新公告為準，本文以一般原則說明，正式報稅前請查 [財政部稅務入口網](https://www.etax.nat.gov.tw)。

## 誰可以列報？資格 4 條件

要符合**全部**才能列報：

1. **房屋登記在納稅本人、配偶或受扶養親屬名下**
2. **同年度已申報該屋為「自用住宅地價稅」**（非營業、非出租）
3. **同年度未列報「房屋租金支出」扣除額**（兩者只能擇一）
4. **每戶（綜合所得稅申報戶）僅限一屋**

「自用」是關鍵。如果你把房子部分出租、放公司登記、或長期空置出租，這項扣除可能被否准。

## 怎麼算？扣抵金額公式

扣抵金額有上限，公式：

```
可扣抵 = min(
  當年度實際支付利息 − 當年度儲蓄投資特別扣除額,
  300,000
)
```

注意第二項：**當年度儲蓄投資特別扣除額**會先抵掉。例如你今年有 5 萬利息收入（銀行存款、ETF 配息等）：

- 已自動列入儲蓄投資特別扣除（最高 27 萬）
- 房貸利息要先**減掉這 5 萬**才能列報

若你年利息支付 25 萬、利息收入 5 萬：
$$\text{可扣抵} = \min(250000 - 50000, 300000) = 200000$$

## 實例：到底省多少所得稅？

假設：年薪 120 萬、房貸 800 萬 30 年 2.1%，當年付利息約 16 萬，無其他利息收入。

| 項目 | 金額 |
|------|------|
| 年所得 | 120 萬 |
| 房貸利息扣除 | 16 萬 |
| 標準扣除（單身）| 12.4 萬 |
| 免稅額 | 9.7 萬 |
| ... |  |
| **節稅效果（約）** | **約 3.2 萬**（按邊際稅率 20%）|

每年省 3 萬左右，**30 年累積近 100 萬**——這還只是 16 萬利息的情境。第一年利息更高（接近 22 萬上限附近的方案能省更多）。

## 需要保留哪些單據

報稅時需附下列證明：

1. **房貸利息單**（銀行每年初寄發；逾期可向銀行櫃台補申請）
2. **房屋稅單**（證明自用住宅）
3. **房屋與土地所有權狀**（首次申報時）
4. **戶口名簿**（證明本人/配偶/扶養親屬實際居住）

電子報稅可以線上撈取，但建議**自行對帳**，銀行偶爾會少傳。

## 跟「房屋租金」扣除額擇一

如果你**同年同時有貸款利息和租金支出**（例如貸款買的房子裝潢中、自己另租屋），**兩項只能擇一申報**。

擇優條件：
- 利息扣除上限 **30 萬**
- 租金扣除上限 **12 萬**（自 2024 年起調整為 18 萬，請以最新公告為準）

通常利息扣除較多。但若你利息已經很低（如已繳很久剩餘本金小），租金 12-18 萬可能更划算。

## 常見錯誤與被退件原因

1. **未申報自用住宅地價稅** → 銀行給的利息單被退件
2. **房屋部分出租**（如把套房分租出去）→ 違反「無出租」要求
3. **未保留利息單原本** → 抽查時無法證明
4. **同戶內申報多屋利息** → 每戶只能一屋
5. **錯把「房屋稅」當成「地價稅」** → 兩者不同

## 結語

房貸利息抵稅是台灣房貸族「**繳了利息政府還幫你部分補貼**」的最大福利之一。**符合資格就一定要報**，每年省下的可能是好幾萬。
